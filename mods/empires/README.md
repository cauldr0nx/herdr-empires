# Herdr Empires (mod)

A medieval RTS layout for Herdr: `layouts/empires.json` + `themes/empires.json`
+ this mod. One mod, many roles (`main.js`): resources (top bar), banner (pane
headers), command, selection, minimap, herald, menu, dialog. `kit.js` draws the
stone bevels, wood planks, parchment and gold trim in whole design pixels at any
zoom; Options switches 1×/2× HUD scale. `data.js` maps Herdr's model to the RTS
view (pure functions, `bun test`).

The bundled fonts (Cinzel, Alegreya Sans, Alegreya Sans SC; SIL OFL 1.1, see
`fonts/OFL.txt`) load with this mod; no system installation is needed.

Keys (`keys.json`, section `layout:empires`): `empires.idle` (Alt+.),
`empires.alarm` (Alt+,), `empires.menu` (Alt+M), `empires.train` (Alt+T),
`empires.garrison` (Alt+G), `empires.toggle_hud` (Ctrl+Shift+H),
`empires.techtree` (F1); also `options`, `chronicle`, `boot`.

Every non-JS file here is listed in `assets.manifest.json` with its license
(`bun tools/asset-check.ts`). Art and sounds are generated by `art/*.ts` in the
repository root; nothing here comes from any commercial game.
